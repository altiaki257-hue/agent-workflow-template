# Known limits

- Model IDs, free quotas, external APIs and agent clients change; verify before use.
- Credentials and local account confirmations are deliberately absent. Configure integrations explicitly outside Git.
- Permissions are application guardrails, not an operating-system sandbox.
- Obsidian cloud sync requires the app and configured plugin to be available; a CLI acknowledgement is not upload proof.
- Automated scanners cannot guarantee absence of every kind of personal information or secret. This template has no imported Git history, hosted logs, issues or artifacts.
- Private operational history and its verification claims are omitted. Run local checks on your own setup.
